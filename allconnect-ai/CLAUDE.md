## 디자인 규칙 (awesome-design-md의 Vercel 디자인 철학 기반)
- 바탕은 흰색 계열, 얇은 선, 은은한 그림자, 둥근 검정 버튼, 로고색(하늘색~파랑) 그라디언트 배경.
- **색 구분**: 제목은 파란색(`--blue`), **세부 내용은 모두 검정**(`--ink`/`--body`). 설명 글자를 회색·파랑으로 바꾸지 않습니다.
- 후기 구간만 완전한 파란 배경에 흰 글씨.
- **영문 폰트도 프리텐다드**(`--mono`도 프리텐다드로 지정됨). 다른 영문 폰트를 쓰지 않습니다. 폰트 파일은 `assets/fonts/`에 포함되어 있습니다.
- 헤더 메뉴는 검정, 21px(모바일 메뉴 24px). 로고 옆 AllconnectAI는 검정, 11px.
- 숫자 성과(150+, 98% 등)를 이미지처럼 보여주는 구간은 넣지 않습니다.
- 섹션 위아래 여백은 PC 90px, 모바일 44px. 간격이 넓어 보이면 이 값을 조정합니다.
- 푸터는 로고, 올커넥트AI, ddase1@gmail.com, ©2026 올커넥트AI 만 둡니다. `hello@example.com` 줄은 넣지 않습니다.

## 섹션 구성 (헤더 메뉴: 회사소개, 서비스, 포트폴리오, 후기, 문의)
1. 메인(히어로): AI MARKETING PARTNER 배지(검정 바탕·흰 글씨), 제목, 버튼 2개.
2. 회사소개: 소개 문구 + Team 카드(경력, SNS·AI 교육, 대기업 협력 파트너, TOP CEO 100인) + 3개 박스.
   - 3개 박스에 마우스를 올리면 관련 서비스 카드가 파란 음영으로 강조됩니다(박스 클릭 시 서비스 구간으로 이동).
3. 서비스: 5개 카드(블로그는 "선택") + **4단계 진행 절차**(상담·진단 / 견적·계약 / 기획·제작 / 납품·개선).
4. 포트폴리오: `assets/pf/`의 카테고리별 줄. 모든 줄이 같은 속도(26px/초)로 왼쪽→오른쪽으로 끝없이 이동. 마우스를 올리면 멈추고, 드래그·화살표·확대 보기 지원.
5. 후기: 카카오톡 스타일 메시지 이미지 5장(`assets/chat-1~5.png`). **샘플 문구이며 실제 후기가 아닙니다.**
6. 문의: 성함/기업명·이메일·요청사항 폼 + 카카오톡 채널 버튼. STEP 표시는 사용하지 않습니다.

## 문의 폼 동작
- Netlify Forms(`name="contact"`)로 접수하고, 보낸 뒤 입력 내용을 자동 복사해 카카오톡 채널 채팅창을 여는 버튼을 보여줍니다. 카카오 채널로 자동 전송하는 기능은 없습니다(비즈니스 메시지 API 필요).
- Netlify 프로젝트 설정에서 **Forms → Enable form detection**이 켜져 있어야 이메일로 접수됩니다. 켠 뒤 다시 배포하고 테스트 문의로 확인해야 합니다.

## 아직 준비되지 않은 항목 (준비되는 대로 반영)
- 실제 고객 후기와 성과 수치로 교체 (현재 후기는 샘플)
- 가격·패키지 안내, 사업자 정보(푸터), 개인정보 수집·이용 동의 문구
- 사례 상세(문제→접근→결과), 인스타그램·블로그 링크, 방문 분석·검색 등록
- 주력 타깃: 현재는 병원 중심이 아니라 **넓은 고객층 기준**. 타깃이 정해지면 첫 화면 문구와 포트폴리오 구성을 조정합니다.
- 팀 소개의 수상·협력 문구는 근거(연도, 협력 범위)가 정리되면 구체화합니다.

## 작업 시 주의

- 로컬 확인: `python3 -m http.server` 로 이 폴더를 열면 됩니다(절대 경로 `/assets/...` 사용).
