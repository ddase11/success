# 우리 가족 기도말씀 30

카카오톡 공지의 링크 하나로 가족 3명이 순서대로(아빠 → 엄마 → 딸) 한글 성경을 읽고,
같은 화면에서 영어 성경을 원어민 음성(Web Speech API)으로 듣는 모바일 우선 PWA입니다.

외부 프레임워크, 로그인, 서버, API 키 없이 순수 HTML/CSS/JavaScript로만 동작합니다.

---

## 1. 앱의 목적

- 가족이 정해진 순서(아빠 → 엄마 → 딸, 반복)대로 주제별 성경 구절을 함께 읽습니다.
- 주제는 세 가지이며, 각각 30구절입니다.
  - **기도** — 기도에 관한 30구절
  - **믿음** — 믿음에 관한 30구절
  - **성령** — 성령에 관한 30구절 (서론 + 구절마다 6단계 구성)
- 첫 화면의 주제 버튼은 **한 줄에 세 개씩** 배치됩니다. 주제가 네 개 이상으로 늘어나면 자동으로 다음 줄로 넘어가며,
  역시 한 줄에 세 개씩 정렬됩니다.
- 주제 버튼을 누르면 해당 주제의 구절을 1번부터 순서대로 읽습니다.
  주제별 진행 상황은 서로 따로 저장되어, 기도·믿음·성령을 읽던 자리가 각각 기억됩니다.
- 구절 한 장에 본문이 세 줄로 표시됩니다.
  1. **개역개정** (대한성서공회) — 가족이 소리 내어 읽는 본문
  2. **쉬운 우리말** — 개역개정의 옛 표현을 이해하기 쉽게 풀어 쓴 현대 한국어 (있는 구절만 표시)
  3. **영어(NIV)** — '영어 듣기' 버튼으로 원어민 음성을 들을 수 있음
  (영어 듣기는 선택 사항이며, 듣지 않아도 '다음 말씀'으로 넘어갈 수 있습니다.)
- 읽기 화면의 **'구절 선택'** 버튼을 누르면 번호판이 열려, 원하는 구절 번호로 한 번에 이동할 수 있습니다.
  이미 읽은 구절은 ✓ 표시로 구분됩니다.
- **말씀추가** 버튼으로 원하는 구절을 직접 입력해 기도/믿음/성령 중 원하는 목록 맨 뒤(31번, 32번 …)에 추가할 수 있습니다.
  (직접 추가한 구절에는 1·2·4단계 안내문이 없으므로, 성령 주제에 넣어도 본문·쉬운 우리말·영어만 표시됩니다.)
- 카카오톡 공지 링크 하나로 접속해서 회원가입 없이 바로 사용할 수 있습니다.
- 진행 상황은 기기의 localStorage에 저장되어, 앱을 닫았다 열어도 이어서 읽을 수 있습니다.

### '성령' 주제의 다른 구성

'성령'은 기도·믿음과 달리 구절을 그냥 나열하지 않고, 30구절을 하나의 이야기로 묶어 읽도록 구성되어 있습니다.

- **서론 화면** — '성령' 버튼을 누르면 읽기 화면으로 바로 가지 않고, 30구절을 관통하는
  '성령의 인류 구원 성공 스토리'(6단락)를 먼저 보여 줍니다. 아래의 **'말씀 시작하기'** 버튼을 누르면 Day 1부터 읽기가 시작됩니다.
  (이어서 읽는 중이라면 '○번부터 시작하기'로 바뀝니다.)
- **구절마다 6단계 구성** — 한 구절 화면에 아래 순서대로 표시됩니다.
  1. **1단계 · 이유** — 이 말씀을 알아야 하는 이유
  2. **2단계 · 연관성** — 다른 말씀과 어떻게 이어지는지
  3. **3단계 · 본문 (개역개정)** — 가족이 소리 내어 읽는 본문
  4. **4단계 · 나눔과 기도** — 함께 나눌 [질문]과 함께 드릴 [기도]
  5. **5단계 · 쉬운 우리말** — 현대 한국어 본문 (있는 구절만)
  6. **6단계 · 영어 (NIV)** — '영어 듣기'로 들을 수 있는 영어 본문
- 구절 번호 아래에는 그 구절의 별칭(예: `창조의 성령`)이 함께 표시됩니다.
- 1·2·4단계는 성경 본문이 아니라 **가족 묵상을 돕는 안내문**이며, 첨부해 주신 문서의 글을 그대로 옮긴 것입니다.
- 기도·믿음 주제에서는 이 단계 블록과 단계 번호가 표시되지 않고 기존과 똑같이 동작합니다.

### 화면 크기(9:16 세로형 표준 레이아웃)

아이폰과 안드로이드에서 화면 길이가 달라 스크롤해야 했던 문제를 없애기 위해, 앱 전체를 **9:16 세로형 기준**으로
표준화했습니다.

- 앱은 항상 화면 높이에 꽉 맞고, 가로 폭은 9:16 비율을 넘지 않습니다. (태블릿·PC에서는 가운데 정렬된 세로형으로 보입니다.)
- 각 화면은 [머리말 / 본문 / 조작 버튼] 3단 구조이며, **조작 버튼은 항상 화면 안에 고정**되어 있습니다.
- 본문이 아주 긴 구절일 때만 가운데 본문 카드 안에서 스크롤되고, 페이지 전체가 위아래로 밀리지 않습니다.
- 화면이 낮은 기기에서는 글자와 여백이 자동으로 조금 줄어 한 화면에 들어오도록 맞춰집니다.

## 2. 파일별 역할

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조(첫 화면·읽기 화면·완료 화면·오류 화면 등) |
| `styles.css` | 모바일 우선 반응형 디자인, 크림/네이비/골드 배색, 다크모드 대응 |
| `app.js` | 화면 전환, 가족 교대 로직, 음성 재생 제어, localStorage 저장, 데이터 검증 |
| `verses.js` | 주제별 성경 구절 데이터(`BIBLE_THEMES`: 기도 30 + 믿음 30 + 성령 30구절)와 번역본 정보(`BIBLE_TEXT_META`) |
| `manifest.json` | PWA 설치 정보 (앱 이름, 아이콘, 테마 색상 등) |
| `service-worker.js` | 오프라인에서도 이미 열어본 화면이 동작하도록 앱 파일을 캐시 |
| `icons/icon-192.svg`, `icons/icon-512.svg` | 홈 화면/설치 아이콘 |

## 3. 로컬 실행 방법

이 앱은 서비스워커(PWA 오프라인 기능)를 사용하므로, `index.html`을 더블클릭해서
`file://`로 여는 방식은 서비스워커가 등록되지 않아 오프라인 기능이 정상 동작하지 않을 수 있습니다.
(화면 표시, 성경 읽기, 음성 재생 등 핵심 기능은 file://에서도 대부분 동작하지만, 정확한 테스트를 위해
아래처럼 로컬 서버로 실행하는 것을 권장합니다.)

터미널에서 `family-prayer-bible` 폴더로 이동한 뒤, 아래 중 하나를 실행하세요.

```bash
# Python 3가 설치되어 있는 경우
python3 -m http.server 8000

# Node.js가 설치되어 있는 경우
npx serve .
```

이후 브라우저에서 `http://localhost:8000` 으로 접속합니다.

## 4. 성경 본문 입력·수정 방법

`verses.js` 파일의 `window.BIBLE_THEMES` 배열을 수정합니다. 주제마다 아래 구조를 지켜야 합니다.

```js
window.BIBLE_THEMES = [
  {
    key: "prayer",          // 저장소 구분용 영문 키. 한 번 정하면 바꾸지 마세요.
    name: "기도",            // 홈 화면 버튼에 표시될 이름
    verses: [
      {
        id: 1,                                   // 1부터 빠짐없이 1씩 증가, 중복 불가
        referenceKo: "빌립보서 4장 6절",           // 한글 장·절
        referenceEn: "Philippians 4:6",          // 영문 장·절
        korean: "개역개정 본문",                   // 실제 번역본 원문 그대로
        koreanModern: "쉬운 우리말 본문",          // 선택 항목 — 없으면 그 줄이 표시되지 않음
        english: "English text"                  // 실제 번역본 원문 그대로
      }
      // ...
    ]
  },
  { key: "faith", name: "믿음", verses: [ /* ... */ ] },

  // '성령'처럼 서론과 단계별 구성이 있는 주제
  {
    key: "spirit",
    name: "성령",
    intro: {                                     // 선택 항목 — 있으면 서론 화면이 먼저 나옴
      title: "오순절 기하성 영성 중심: 성령충만 30개 구절",
      heading: "서론: 30개 구절을 관통하는 ...",
      paragraphs: ["첫 단락", "둘째 단락" /* ... */]
    },
    verses: [
      {
        id: 1,
        title: "창조의 성령",                     // 선택 항목 — 구절 별칭
        referenceKo: "창세기 1장 2절",
        referenceEn: "Genesis 1:2",
        reason: "1단계 · 이 말씀을 알아야 하는 이유",      // 선택 항목
        connection: "2단계 · 다른 말씀과의 연관성",        // 선택 항목
        korean: "3단계 · 개역개정 본문",
        question: "4단계 · 함께 나눌 질문",               // 선택 항목
        prayer: "4단계 · 함께 드릴 기도",                 // 선택 항목
        koreanModern: "5단계 · 쉬운 우리말 본문",
        english: "6단계 · English text"
      }
      // ...
    ]
  }
];
```

- 주제를 새로 추가하려면 위 구조로 항목을 하나 더 넣기만 하면 됩니다. 홈 화면 버튼과 '말씀추가'의 목록 선택 버튼은
  이 배열을 보고 자동으로 만들어집니다. (코드 수정 불필요)
- `key`는 진행 기록을 저장하는 기준이므로, 이미 사용 중인 주제의 `key`를 바꾸면 그 주제의 읽기 기록이 초기화됩니다.
- `koreanModern`(쉬운 우리말)은 **선택 항목**입니다. 항목이 없으면 그 구절에서는 현대어 줄이 아예 표시되지 않습니다.
  넣을 경우 빈 문자열이면 안 되고, 필요 없으면 항목 자체를 지우면 됩니다.
- `title`, `reason`, `connection`, `question`, `prayer`도 모두 **선택 항목**입니다. 넣은 구절에서만 해당 블록이
  표시되며, 하나라도 들어 있으면 그 구절에 3·5·6단계 번호표가 함께 붙습니다. 이 항목들은 성경 본문이 아니라
  묵상 안내문이므로, 성경 저작권 고지(`BIBLE_TEXT_META`)의 대상이 아닙니다.
- `intro`(주제 서론)도 **선택 항목**입니다. 넣으면 `title`, `heading`, `paragraphs`(비어 있지 않은 배열)가 모두
  채워져 있어야 하며, 그 주제를 시작할 때 서론 화면이 먼저 나옵니다. 없으면 기존처럼 바로 읽기 화면으로 들어갑니다.
- 4개 필드(`referenceKo`, `referenceEn`, `korean`, `english`) 중 하나라도 비어 있거나, id가 1부터 순서대로 이어지지
  않으면 앱 시작 시 자동 검증에서 실패로 처리되어 "성경 데이터에 누락 또는 오류가 있습니다" 오류 화면이 표시됩니다.
- 본문에 HTML 태그나 스크립트로 의심되는 내용이 포함되면 검증에서 오류로 표시됩니다.
- 번역본을 변경한 경우, `window.BIBLE_TEXT_META`의 `koreanVersionName`/`englishVersionName`/저작권 고지 문구도
  실제 사용한 번역본에 맞게 함께 수정해야 합니다. (아래 11번 항목 참고)

**앱 안에서 구절 추가하기('말씀추가' 기능)**

`verses.js`를 직접 편집하지 않고도, 첫 화면의 '말씀추가' 버튼으로 새 구절을 추가할 수 있습니다.
먼저 어느 목록(기도/믿음/성령)에 넣을지 고른 뒤, 권(책 이름)·장·절과 한글/영어 본문을 직접 입력하면
그 주제의 목록 뒤에 새 번호(31번, 32번, …)로 저장됩니다.
이 앱은 외부 성경 API나 서버를 사용하지 않으므로(요구사항: API 키/서버 없이 동작), 책/장/절만 입력하면
본문이 자동으로 채워지는 기능은 없습니다 — 본문은 반드시 실제 성경에서 그대로 옮겨 직접 입력해야 합니다.
추가한 구절은 이 기기의 localStorage에 저장되며(다른 기기와 자동으로 공유되지 않음), '처음부터 다시 시작'으로
읽기 기록을 초기화해도 삭제되지 않습니다.

## 5. 가족 이름 기본값 변경 방법

기본값은 `app.js` 상단의 다음 부분입니다.

```js
var DEFAULT_NAMES = ['아빠', '엄마', '딸'];
```

이 배열의 순서가 그대로 1번째·2번째·3번째 읽는 사람이 되며, 구절 번호를 3으로 나눈 나머지로
자동 배정됩니다. 사용자는 첫 화면의 '가족 이름 설정'에서 직접 이름을 바꿀 수 있고,
바꾼 이름은 이 기기의 localStorage에 저장되어 계속 사용됩니다.

## 6. 음성이 나오지 않을 때 해결 방법

1. 이 앱은 브라우저 내장 기능인 **Web Speech API(speechSynthesis)**를 사용합니다.
   별도 설치나 API 키가 필요 없지만, 브라우저/기기가 지원해야 합니다.
2. 음성이 전혀 나오지 않으면: 기기의 음소거 스위치, 미디어 볼륨을 먼저 확인하세요.
3. 카카오톡 인앱 브라우저에서 소리가 나오지 않으면, 화면 우측 상단(또는 하단) 메뉴에서
   **"다른 브라우저로 열기"(Chrome/Safari 등)**를 선택해 실행해 보세요. 인앱 브라우저는
   음성합성 지원이 기기/버전마다 다를 수 있습니다.
4. 음성 목록이 설치되어 있지 않은 안드로이드 기기는 "설정 > 접근성(또는 일반) > 텍스트 음성 변환"에서
   Google 음성 데이터(영어)를 설치해야 할 수 있습니다.
5. 음성합성을 전혀 지원하지 않는 환경에서는 '영어 듣기' 버튼 대신 안내 문구가 표시되고,
   화면에 보이는 영어 본문을 직접 읽으면 됩니다. 이 경우에도 '다음 말씀' 버튼은 정상적으로 눌러
   다음으로 진행할 수 있습니다.

## 7. 카카오톡 인앱 브라우저 사용 방법

- 카카오톡 공지사항이나 채팅방에 올린 링크를 누르면 카카오톡 내장 브라우저로 바로 열립니다.
- 화면 표시, 한글/영어 본문 읽기, 다음/이전 이동, 진행 저장은 인앱 브라우저에서도 동작합니다.
- 음성 재생이나 PWA 설치가 원활하지 않다면, 우측 상단 "···" 메뉴에서 "다른 브라우저로 열기"를 선택하세요.

## 8. 홈 화면에 추가하는 방법

- 이 자동화 테스트 과정에서 **실제 버그들을 발견해 수정**했습니다.
  1. `[hidden]` 속성이 지정된 화면 요소들이 `.screen`/`.dialog-overlay` 클래스의 `display: flex` 규칙에 가려
     실제로는 사라지지 않고 여러 화면이 겹쳐 보이는 문제 → `styles.css`에 `[hidden] { display: none !important; }`
     규칙을 추가해 수정했습니다.
  2. 브라우저의 음성 엔진이 `onend`나 `onerror` 콜백을 전혀 호출하지 않고 멈춰버리는 경우(테스트 환경에서 재현됨),
     사용자가 '다음 말씀' 버튼을 영영 누르지 못하고 멈추는 문제 → `app.js`의 음성 재생 로직에 15초 감시
     타이머(watchdog)를 추가해, 응답이 없으면 자동으로 오류로 처리하고 다음 단계로 진행할 수 있게 했습니다.
  3. 선택 버튼(시작 구절·글자 크기)의 선택 표시 CSS 선택자가 실제 클래스와 달라, 눌러도 아무 반응이 없어 보이던 문제.
  4. '말씀추가' 폼 제출이 디바운스 잠금에 걸리면 `e.preventDefault()`가 실행되지 않아 페이지가 새로고침되며
     앱 상태가 사라지던 문제.
  5. 서비스워커가 캐시 우선 방식이라 새 버전을 배포해도 기존 방문 기기에 반영되지 않던 문제
     (네트워크 우선 + 캐시 버전 관리 + `updateViaCache: 'none'`으로 수정).
  6. 첫 방문 시 서비스워커가 처음 제어권을 잡는 순간에도 화면이 한 번 불필요하게 새로고침되던 문제
     (업데이트일 때만 새로고침하도록 수정).
- 실제 실행 중인 헤드리스 브라우저에는 시스템 음성엔진이 설치되어 있지 않아 영어 듣기 버튼을 누르면
  항상 `synthesis-failed` 오류가 발생합니다. 이는 테스트 환경의 제약이며, 이 오류가 발생했을 때도 앱이
  안내 문구를 보여주고 '다음 말씀' 버튼을 정상적으로 활성화하는 오류 복구 동작 자체는 확인했습니다.
  다만 실제 음성이 재생되어 끝까지 들리는 것 자체는(음성 엔진이 없어) 이 환경에서 직접 들어보지 못했으므로,
  실제 스피커로 들리는 음질·목소리는 실제 모바일 기기에서 추가로 확인이 필요합니다.
- **'성령' 주제를 Playwright로 41개 항목 검증해 모두 통과했습니다**(390×844 / 360×800).
  - 주제 버튼 3개가 **한 줄에 세 개**로(같은 y좌표, 왼쪽→오른쪽) 배치되고 3열 그리드로 구성됨
  - '성령'을 누르면 읽기 화면이 아니라 **서론 화면**이 먼저 뜨고, 제목·6단락이 모두 표시되며,
    페이지 전체가 아니라 본문 영역만 스크롤됨
  - '말씀 시작하기'를 누르면 Day 1(창세기 1장 2절)로 진입하고, 별칭 `창조의 성령`이 표시됨
  - 한 화면에 **1단계 이유 → 2단계 연관성 → 3단계 본문 → 4단계 나눔/기도 → 5단계 쉬운 우리말 → 6단계 영어**가
    문서에 적힌 그 순서대로 표시되는지 각 요소의 y좌표로 직접 검증
  - 내용이 길어진 뒤에도 페이지 전체 스크롤이 없고 '영어 듣기'·'다음 말씀'이 화면 안에 유지됨
  - '구절 선택'으로 27번(갈라디아서 5장 22-23절)으로 점프해 별칭·NIV 두 절이 모두 표시됨
  - 기도 주제에서는 단계 블록·단계 번호·별칭 줄이 모두 숨겨져 기존과 동일하게 동작함
  - 테스트 중 수집한 브라우저 콘솔 오류 없음
- **`verses.js`의 '성령' 주제를 첨부 문서 원문과 전수 대조**했습니다. 서론 6단락과 30일 전부에 대해
  1·2·3·4단계 본문이 문서와 한 글자도 다르지 않은지, 참조·별칭이 머리글과 일치하는지,
  5·6단계가 모두 채워져 있는지 스크립트로 확인했습니다(불일치 0건).
- 이번 업데이트 중 **기존 버그 두 가지를 추가로 발견해 수정**했습니다.
  1. 본문 앞뒤 따옴표·괄호를 떼어내는 처리가 **짝이 맞는 괄호까지 잘라내던 문제**.
     시편 62편 8절의 `(셀라)`가 `(셀라`로, 요한복음 7장 39절의 괄호 설명도 끝 괄호가 잘려 보였습니다.
     → 본문 전체를 감싼 한 겹만 벗기고, 안에서 짝이 맞는 괄호·따옴표는 그대로 두도록 고쳤습니다.
  2. 화면 낭독용으로 숨겨둔 제목(`.sr-only`, `position: absolute`)이 `#app`의 `overflow: hidden`에 갇히지 않아,
     본문이 길어지면 **페이지 전체가 스크롤되던 문제** → `#app`에 `position: relative`를 지정해 고쳤습니다.
     (성령 주제처럼 내용이 길어지면서 드러난 문제이며, 기존 주제에도 잠재해 있던 버그입니다.)
- 색상 대비를 WCAG 공식으로 직접 계산해 확인했습니다(예: 네이비 텍스트/크림 배경 13.18:1, 골드 텍스트/카드 배경
  4.86:1 등). 이 과정에서 장·절 표시에 쓰인 골드 색상의 대비가 다소 낮은 것을 발견해 텍스트 전용으로
  더 진한 골드 색상(`--color-gold-text`)을 추가하고 교체했습니다.

### 알려진 제한사항 (남아있는 항목)
- Web Speech API의 실제 음성 목록과 음질은 브라우저·OS·기기에 따라 크게 달라집니다.
  "en-US + Natural" 음성이 없는 기기에서는 우선순위에 따라 차선 음성이 자동 선택됩니다.
  실제 스피커로 들리는 음성 품질은 이번 자동화 테스트로 확인하지 못했으므로, 배포 후 실제 기기에서 들어봐야 합니다.
- 카카오톡 인앱 브라우저의 음성합성 지원 여부는 기기/카카오톡 버전에 따라 다를 수 있어,
  실제 배포 후 가족이 사용하는 기기에서 추가 확인이 필요합니다.
- iOS Safari의 apple-touch-icon은 SVG를 완벽히 지원하지 않는 버전이 있을 수 있습니다.
  더 선명한 아이콘이 필요하면 192×512 PNG로 별도 변환해 교체하는 것을 권장합니다.
- 한글 개역개정 본문의 공식 사용 허가 확인은 아직 완료되지 않았습니다(11번 항목 참고).
- '성령' 주제의 **Day 10 별칭(`성령을 주시는 아버지`)은 제공 문서에 없는 이름**입니다. 문서에 Day 10의 머리글 줄이
  통째로 빠져 있어 사용자가 직접 지정한 이름을 넣었습니다.
  (구절 자체가 누가복음 11장 13절이라는 점은 문서의 서론·Day 18 2단계로 확인했습니다.)
- '성령' 주제의 1·2·4단계 안내문과 서론은 성경 본문이 아니라 제공 문서 작성자가 쓴 글입니다.
  내용의 신학적 타당성은 이 앱이 검증하지 않으며, 문서 그대로 표시합니다.
- 서비스워커 오프라인 동작은 로컬 서버 기준으로 캐시 등록/경로 일치만 확인했으며, 실제 배포 후
  비행기 모드 등에서의 완전한 오프라인 재접속 테스트는 별도로 수행하지 않았습니다.
