사용 방법

  1. ‘기도’ 버튼을 누르면 가족 이름 차례가 바로 표시됩니다.
  2. 해당 가족이 한글 성경 본문을 직접 소리 내어 읽습니다.
  3. ‘영어 듣기’ 버튼을 눌러 영어 본문을 원어민 음성으로 들을 수 있습니다. (선택 사항이며, 여러 번 눌러 같은 구절을 계속 다시 들어도 됩니다.)
  4. ‘다음 말씀’ 버튼을 눌러야 다음 구절로 넘어갑니다. 넘어가면 읽을 사람이 자동으로 바뀝니다. (아빠 → 엄마 → 딸 순서 반복)
  5. ‘이전 말씀’ 버튼으로 이전 구절로 돌아갈 수 있고, ‘처음 화면’ 버튼으로 언제든 첫 화면으로 돌아갈 수 있습니다.
  6. 모든 말씀을 다 읽으면 완료 화면이 나타납니다.
  7. ‘말씀추가’ 버튼으로 직접 성경 구절을 입력해 기도 목록에 새 구절을 추가할 수 있습니다.
