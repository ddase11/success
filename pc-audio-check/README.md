# PC 소리 → 근처 블루투스 이어폰 유출 점검

내 Windows PC에서 나오는 소리를 **근처 사람이 블루투스 이어폰(AirPods 등)으로 들을 수 있는지** 확인하는 읽기 전용 점검 도구입니다. 설정은 바꾸지 않습니다.

## 사용법

1. 이 폴더(`pc-audio-check`)를 Windows PC에 내려받습니다.
2. `run-check.bat` 을 더블클릭합니다.
3. 결과가 화면에 나오고, 같은 폴더에 `audio-check-report.txt` 로 저장됩니다.

PowerShell에서 직접 실행할 수도 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Check-BluetoothAudioLeak.ps1
```

관리자 권한은 필요 없습니다. 의심되는 상황(예: 상대방이 가까이 있을 때 음악·영상을 틀어 둔 상태)에서 실행하면 4번 항목에 "어떤 프로그램이 어느 출력 장치로 소리를 내는지"가 나와 가장 정확합니다.

## 점검 항목

| # | 항목 | 확인 내용 |
|---|------|-----------|
| 1 | 블루투스 어댑터 | 블루투스가 켜져 있는지 |
| 2 | 페어링된 기기 | 등록된 블루투스 기기 목록과 지금 연결 여부 (모르는 AirPods가 있는지) |
| 3 | 블루투스 오디오 서비스 | A2DP(음악), 핸즈프리, LE Audio/Auracast 통로가 활성인지 |
| 4 | 출력 장치별 프로그램 | 각 스피커/이어폰 장치로 소리를 내는 프로그램(PID, 실제 음량 Peak 포함) |
| 5 | 네트워크 전송 | AirPlay·Spotify Connect·Chromecast·통화 앱 실행 여부, AirPlay/Cast 포트 연결 |
| 6 | 원격 접속 | 원격 데스크톱, TeamViewer·AnyDesk 등 (원격 접속자에게 소리 전달 가능) |

## 알아두면 좋은 점

- **블루투스 이어폰은 PC와 페어링되어야만 소리를 받습니다.** AirPods는 근처 PC의 소리를 몰래 "엿듣는" 기능이 없고, 페어링은 PC의 Bluetooth 설정에서 사용자가 직접 추가·승인해야 합니다. 2번에 아무 기기도 없으면 블루투스로 소리가 나갈 수 없습니다.
- **Apple 사용자에게 현실적인 경로는 블루투스보다 네트워크입니다.** PC에 AirPlay 송신 프로그램(AirParrot, TuneBlade, Airfoil, iTunes의 AirPlay 스피커 등)이 있으면 같은 Wi-Fi의 iPhone/Mac/Apple TV로 소리가 가고, 그 기기에 연결된 AirPods로 들을 수 있습니다. 5번에서 확인합니다.
- 통화 앱(카카오톡, Discord, Zoom, Teams)에서 화면 공유 + "소리 공유"를 켜면 상대방에게 PC 소리가 전달됩니다.
- 스피커로 나오는 소리는 당연히 근처에서 그냥 들립니다. 이는 이 도구의 점검 대상이 아닙니다.

## 문제가 발견되면

- 모르는 블루투스 기기: **설정 > Bluetooth 및 장치 > 해당 기기 `...` > 장치 제거**, 필요 없으면 블루투스 끄기
- 모르는 프로그램: 작업 관리자에서 종료 후 **설정 > 앱** 에서 제거
- 출력 장치 확인: **설정 > 시스템 > 소리 > 볼륨 믹서** 에서 앱별 출력 장치 확인
